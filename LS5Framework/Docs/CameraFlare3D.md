# Camera flares

Instance `res://LS5Framework/Scenes/Effects/CameraFlare/CameraFlare3D.tscn` beneath a source node. The default source is its parent. Finite sources use the source origin plus `Source Offset`; directional sources use the source's world positive Z axis, matching the direction toward a `DirectionalLight3D` sun. An empty source path uses the flare node itself.

The combined `EnvironmentWeatherSystem` contains a `SunFlare` instance targeting `DayNightCycle/Sun`. Select this child to disable or tune the effect per environment. The sun's visibility and energy attenuate the effect automatically. The optional weather-cycle reference also reduces intensity with overcast coverage during weather transitions; this is broad weather attenuation rather than individual procedural-cloud sampling.

Sun and lens images fade in opacity and grow when visible, then fade and shrink when leaving the camera view or entering cover. Screen-edge fading starts inside the viewport. The bleach wash increases smoothly within the configured angle around the camera's viewing direction. A separate circular bleach image grows over the source, with its own diameter, tint, and softened circular edge. All components share obstruction visibility; both bleach layers also share an alignment fade.

Five physics rays sample the source center and four nearby directions at the configured interval. The default physics obstruction mask is world layer 1; select additional layers for other collision surfaces. Areas are ignored, and collision ancestors of the source and camera are automatically excluded. Add explicit collision exclusions for other objects that should not block the physics test. The directional distance limits how far these rays test; finite sources test the actual distance to the source.

`Mesh Obstruction Enabled` additionally samples actual rendered silhouettes, including skinned player models and meshes without collision. A transparent 16×16 viewport shares the active camera's world and renders only the narrow angle around the source at the obstruction interval. Alpha coverage within the source footprint controls visibility; this tests animated geometry rather than broad mesh bounds. The probe has no input, canvas, sky, fog, post effects, or positional shadow atlas. It updates only when the source is in view, and its result shares the normal visibility fade. Camera changes invalidate pending results. `Mesh Obstruction Mask` filters render layers together with the main camera's cull mask; it does not change mesh visibility or materials in the gameplay viewport. Use an excluded render layer for visible source geometry that should not occlude its own flare. Headless servers retain physics obstruction without creating a rendering probe.

Each lens element has its own texture, tint, diameter, and position along the source-to-screen-center axis. Position zero follows the source, one reaches screen center, and two lies equally far beyond center. Sun and lens sizes use viewport height, preserving circular shapes at any aspect ratio. Bleach size uses the viewport diagonal to cover ultrawide views without stretching. The effect follows the viewport's active camera unless a camera path is assigned, resets its visibility on camera changes, and draws on canvas layer 0 beneath the gameplay HUD without intercepting input.

The Shared pack owns the reusable scene, scripts, shaders, and four textures. Windows, Linux, and macOS runtime lists also include the two scripts for startup class registration. No editor-only APIs or generated image resources are required.
